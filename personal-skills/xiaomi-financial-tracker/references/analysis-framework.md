# Analysis Framework

Use this structure for every `report.md`.

```markdown
# 小米集团财报跟踪：<source_period>

## 1. 一页结论
## 2. 数据覆盖与缺口
## 3. 核心数据表
## 4. 单季与累计数据
## 5. 分业务板块分析
## 6. 同比和环比变化原因
## 7. 外部影响因素
## 8. 当前基本面判断
## 9. 估值位置
## 10. 未来 3 财年预测
## 11. 风险、挑战与下一期观察清单
## 12. 数据来源、置信度与待复核项
```

## 分析重点

智能手机：判断收入变化来自销量、ASP、毛利率、渠道、存储成本还是竞争格局。

AIoT：判断收入增长、毛利率、大家电放量、设备连接数和多设备用户是否改善。

互联网服务：判断 MAU、收入、毛利率和广告/游戏/增值服务结构。

智能汽车：判断交付、ASP、毛利率、经营亏损或利润、门店覆盖、研发和销售投入。

集团：判断总收入、经调整净利润、整体毛利率、现金储备、研发强度和费用结构。

估值：结合 TTM PE、Adjusted TTM PE、PB、历史百分位和利润周期，不单独用百分位下结论。

预测：区分官方指引、券商预测、公开预测和情景假设，说明关键假设和不确定性。

风险：关注手机存储成本、消费电子周期、EV 价格战、交付爬坡、海外扩张、研发投入和监管风险。
