# Qoder 候选资料总览

本目录是 Qoder 学习资料的候选入口，只在人工批准后才会发布。它按能力主题路由到不可变 record；产品行为、配置语义和来源仅在 record 的 FACT blocks 中维护。

## 快照与版本边界

本候选的路由标签为 `unversioned-docs-2026-07-29`，表示 2026-07-29 核对的 Qoder 官方在线文档快照。它不是 Qoder 供应商发布的桌面、CLI 或其他产品版本，也不表示版本生命周期、支持承诺或当前安装实例的能力。

请先阅读 [版本索引](version-index.md)，再按问题选择能力索引。各能力均保留 `unverified` 状态；这表示本地资料没有可绑定的供应商产品版本，不能将文档快照当作已确认的版本支持，也不能把未确认理解为不支持。
