# 风格手册

## 色板

| 变量 | 值 | 用途 |
|---|---|---|
| `--navy` | `#003B5C` | 标题、深色面板底、正文重点 |
| `--blue` | `#0070AD` | 小标签、数字、流程节点、进度条 |
| `--sky` | `#00A3E0` | 只出现在进度条渐变，不单独用 |
| `--accent` | `#8E3B45` | 强调：标题后半句、序号徽标、当前页标记 |
| `--accent-soft` | `--accent` 混白 24% | 深色底上的强调文字 |
| `--accent-tint` | `--accent` 混白 6% | 警示条的浅底 |
| `--ink` | `#0F2233` | 正文 |
| `--ink2` | `#3B5266` | 次级正文 |
| `--muted` | `#7A8FA3` | 说明、单位、脚注 |
| `--line` | `#DCE7F0` | 卡片描边 |
| `--line2` | `#EAF1F7` | 分隔线 |
| `--paper` | `#FBFDFE` | 卡片底色 |
| `--tint` | `#EEF5FB` | 表头、选中行的浅底 |
| `--tint-soft` | `#F4F9FD` | 流程节点底 |
| `--line-blue` | `#DCE9F4` | 节点描边 |
| `--brand-h` | `28px` | logo 高度；改它标题区留白会跟着重算 |

**只用这两个色系**：冷蓝（navy/blue）+ 一点酒红。不要引入绿色、橙色、紫色。需要第三档时用中性灰阶（`#C8D8E4` / `#93ABBE` / `#A6B8C8`）。

强调色 `--accent` 在深色底上要换成 `--accent-soft`，否则对比不足。两个派生色都由 `--accent` 自动算出，换品牌色不用改任何地方。

## 字号

| 元素 | 字号 | 字重 | 说明 |
|---|---|---|---|
| 封面主标题 | 57px / 1.15 | 800 | 最多两行 |
| 内页标题 | 40px / 1.22 | 800 | 最多两行，第二行用 `<em>` 上强调色 |
| 导语 | 15px / 1.72 | 400 | 一到两句，不超过三行 |
| 卡片标题 | 14px | 700 | 一行 |
| 卡片正文 | 12.8px / 1.68 | 400 | 两到三行 |
| 数字 | 36px | 800 | 等宽数字 |
| 小标签 | 11.8px | 700 | `letter-spacing:.06em` |
| 脚注 | 10.5–11px | 400 | 来源、页码 |

同一屏内字号层级不要超过四档。最小 10px，低于 10px 投影看不清。

## 间距

- 页面内边距：`46px 64px 54px`（上 / 左右 / 下）
- 标题到导语：9px；导语到正文区：20px
- 卡片间隙：11–13px；两栏间隙：22–28px
- 卡片内边距：`16px 18px`；数字块 `20px`

间距靠 flex 的 `gap`，不要用 `margin` 堆。

## 密度

一页的信息量控制在：**1 个结论 + 3–5 个支撑点**。

- 正文区底部留白 > 15% 视为空页，要补内容或换版式
- 正文文字总量 > 220 字视为过密，拆页
- 卡片里超过三行文字，说明这段该单独成页

## 对齐的三条铁律

1. 同一行的卡片、面板，顶边和底边都要对齐（用等高行，不要各自居中）
2. 页面左右边距永远 64px，任何元素不得越过
3. 数字右对齐、文本左对齐，不要混排

## 不要做的事

- ❌ 给卡片内部的文字块加 `flex:1` → 文字被拉开，出现空心盒子（卡片本身用 `flex:1` 均分列高没问题，配 `justify-content:center`）
- ❌ 左右两栏各自 `justify-content:center` → 顶边错位
- ❌ 一页三种以上字号强调
- ❌ 红、橙、绿等高饱和色
- ❌ 阴影、渐变、圆角大于 12px 的装饰块
- ❌ 为了一页去改 `deck.css`（改不动就是版式选错了）；版式片段里自带的 inline 比例不算违规，照抄即可
- ❌ 图表用第三方库（纯 CSS 就够，还能离线）

## 加一个新版式

版式不够用时按这四步加，不要临时写一页 inline 样式：

1. `assets/deck.css` 新增一组组件类，命名跟现有风格一致（`.xxx` 容器 + `.xxx .yy` 子元素），只用已有令牌
2. `references/layouts.md` 追加一节，写清**何时用 / 插入位置 / 片段 / 注意**
3. `SKILL.md` 的「选版式」表加一行，让下一个 agent 能选到它
4. 生成一份含该版式的片子，跑 `verify.mjs` 确认无越界，再看截图

只加一页专用、别处不复用的样式，说明版式选错了，不是 CSS 不够用。
